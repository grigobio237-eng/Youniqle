# 프로젝트 규칙 (Project Rules)

## 1. 언어 설정 (Language)
- **기본 언어**: 모든 설명, 주석, 문서(Markdown)는 **한국어(Korean)**로 작성한다.
- **코드**: 변수명, 주석 등은 영어를 사용할 수 있으나, 주요 로직에 대한 설명은 한국어를 권장한다.

## 2. 문서 관리 (Documentation)
- 모든 아티팩트(`task.md`, `implementation_plan.md` 등)는 한국어로 유지 관리한다.
- 사용자에게 제공하는 가이드나 스크립트 사용법도 한국어로 작성한다.

## 3. 채팅 (Chat)
- 사용자와의 대화는 한국어로 진행한다.
