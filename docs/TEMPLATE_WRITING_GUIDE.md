# 📝 알림 템플릿 작성 가이드

## 🎯 개요

알림 템플릿은 `{변수명}` 형태의 플레이스홀더를 사용하여 개인화된 메시지를 생성합니다. 이 가이드는 템플릿 작성 시 사용할 수 있는 모든 변수와 작성 방법을 안내합니다.

---

## 🔧 기본 구조

### 플레이스홀더 형식
```
{변수명}
```

### 예시
```
안녕하세요, {name}님!
주문번호 {order_id}가 확인되었습니다.
```

**결과 (실제 발송 시)**:
```
안녕하세요, 김철수님!
주문번호 ORD-2025-001234가 확인되었습니다.
```

## 📝 템플릿 작성 예시

### 1️⃣ **주문 확인 알림**

**템플릿 제목**:
```
{name}님, 주문이 확인되었습니다
```

**템플릿 내용**:
```
안녕하세요, {name}님!

주문번호 {order_id}가 성공적으로 확인되었습니다.
주문일시: {order_date} {order_time}
주문금액: {order_amount}

주문 상품:
• {product_name} ({quantity}개)

배송 예정일: {estimated_delivery}

감사합니다.
{Youniqle} 팀
```

### 2️⃣ **배송 시작 알림**

**템플릿 제목**:
```
🚚 {name}님의 주문이 배송을 시작했습니다
```

**템플릿 내용**:
```
{name}님, 안녕하세요!

주문번호 {order_id}의 상품이 배송을 시작했습니다.

📦 배송 정보
• 운송장번호: {tracking_number}
• 배송업체: CJ대한통운
• 예상도착: {estimated_delivery}

배송 조회: {site_url}/tracking/{tracking_number}

문의사항이 있으시면 {support_email}로 연락해주세요.

감사합니다.
```

**템플릿 제목**:

```

```

```
감사합니다.
{Youniqle} 팀
```

```

{Youniqle} 팀
```

## ⚠️ 작성 시 주의사항

### 1. **변수명 정확성**
- ✅ 올바른 형식: `{name}`, `{order_id}`
- ❌ 잘못된 형식: `{Name}`, `{order-id}`, `{order id}`

### 2. **대소문자 구분**
- 변수명은 **소문자**를 사용하세요
- `{name}` ✅ / `{Name}` ❌

### 3. **공백 주의**
- 중괄호 안에 공백이 있으면 안됩니다
- `{ name }` ❌ / `{name}` ✅

### 4. **한글 변수명**
- 한글 변수명은 사용하지 마세요
- `{이름}` ❌ / `{name}` ✅

### 5. **특수문자**
- 변수명에는 영문, 숫자, 언더스코어(_)만 사용
- `{user-name}` ❌ / `{user_name}` ✅

## 🔍 변수 테스트 방법

### 1. **미리보기 기능**
템플릿 작성 후 "미리보기" 버튼을 클릭하여 실제 데이터로 치환된 결과를 확인할 수 있습니다.

### 2. **테스트 발송**
관리자 패널에서 테스트 발송을 통해 실제 메시지를 확인할 수 있습니다.

### 3. **변수 목록 확인**
템플릿 작성 화면에서 "사용 가능한 변수" 버튼을 클릭하여 현재 사용 가능한 모든 변수를 확인할 수 있습니다.
