# 📋 알림 템플릿 기능 테스트 가이드

## 🎯 개요

알림 템플릿 관리 시스템의 모든 기능이 완성되었습니다. 이 가이드는 각 기능을 테스트하는 방법을 단계별로 안내합니다.

---

## ✅ 완성된 기능 목록

1. ✅ **템플릿 생성** - CreateTemplateDialog
2. ✅ **템플릿 편집** - EditTemplateDialog  
3. ✅ **템플릿 삭제** - DeleteTemplateDialog
4. ✅ **템플릿 상세보기** - ViewTemplateDialog
5. ✅ **템플릿 복제** - 인라인 기능
6. ✅ **번역 관리** - 준비 중 안내
7. ✅ **통계 보기** - 상세보기에 통합

---

## 🧪 테스트 시나리오

### 1️⃣ 템플릿 생성 테스트

#### 접근 경로
```
관리자 로그인 → /admin/notifications/templates
```

#### 테스트 단계
1. **"새 템플릿" 버튼 클릭**
   - 생성 다이얼로그가 열리는지 확인

2. **필수 필드 검증**
   - 빈 상태로 "템플릿 생성" 클릭
   - ✅ "템플릿 이름을 입력해주세요" 에러 표시

3. **정상 데이터 입력**
   ```
   템플릿 이름: 주문 확인 알림
   설명: 주문이 확인되었을 때 발송되는 알림
   타입: 이메일
   카테고리: 주문
   우선순위: 높음
   언어: 한국어
   상태: 활성
   제목: {name}님, 주문이 확인되었습니다
   내용: 주문번호 {order_id}가 확인되었습니다. 곧 배송 준비에 들어갑니다.
   태그: 주문, 확인
   ```

4. **생성 확인**
   - "템플릿 생성" 버튼 클릭
   - ✅ 다이얼로그가 닫힘
   - ✅ 목록에 새 템플릿이 표시됨
   - ✅ "생성 중..." 로딩 표시

#### 예상 결과
- 템플릿이 목록 최상단에 표시
- 모든 입력 값이 정확히 반영됨
- 생성자 정보 표시 (관리자 이름)

---

### 2️⃣ 템플릿 편집 테스트

#### 테스트 단계
1. **템플릿 선택**
   - 목록에서 템플릿 행의 "..." 버튼 클릭
   - "편집" 메뉴 선택

2. **편집 다이얼로그 확인**
   - ✅ 기존 데이터가 모두 채워져 있음
   - ✅ 로딩 인디케이터 표시 후 데이터 로드

3. **데이터 수정**
   ```
   템플릿 이름: 주문 확인 알림 (수정됨)
   상태: 활성 → 초안으로 변경
   ```

4. **저장 확인**
   - "변경사항 저장" 버튼 클릭
   - ✅ 다이얼로그가 닫힘
   - ✅ 목록이 자동으로 새로고침됨
   - ✅ 수정된 내용이 반영됨

#### 예상 결과
- 템플릿 이름과 상태가 변경됨
- 수정 시간이 업데이트됨

---

### 3️⃣ 템플릿 상세보기 테스트

#### 테스트 단계
1. **상세보기 열기**
   - 템플릿 행의 "..." 버튼 → "보기" 선택

2. **표시 정보 확인**
   - ✅ 템플릿 기본 정보 (이름, 설명, 상태)
   - ✅ 설정 정보 (타입, 카테고리, 언어, 우선순위)
   - ✅ 템플릿 내용 (제목, 본문)
   - ✅ 태그 목록
   - ✅ 사용 통계 (전송, 전달률, 열람률)
   - ✅ 메타 정보 (생성자, 생성일, 수정일)

3. **UI 검증**
   - 아이콘이 올바르게 표시되는지 확인
   - 통계 카드의 색상 구분 확인
   - 날짜 형식이 올바른지 확인

#### 예상 결과
- 모든 정보가 깔끔하게 정리되어 표시됨
- 색상과 아이콘으로 정보 구분이 명확함

---

### 4️⃣ 템플릿 삭제 테스트

#### 테스트 단계
1. **삭제 다이얼로그 열기**
   - 템플릿 행의 "..." 버튼 → "삭제" (빨간색) 선택

2. **확인 메시지 검증**
   - ✅ 경고 아이콘 표시
   - ✅ 템플릿 이름이 정확히 표시됨
   - ✅ "되돌릴 수 없습니다" 경고 메시지

3. **취소 테스트**
   - "취소" 버튼 클릭
   - ✅ 다이얼로그 닫힘
   - ✅ 템플릿이 그대로 유지됨

4. **삭제 확인**
   - 다시 삭제 메뉴 선택
   - "삭제" 버튼 클릭
   - ✅ "삭제 중..." 표시
   - ✅ 목록에서 제거됨

#### 예상 결과
- 삭제된 템플릿이 목록에서 사라짐
- 다른 템플릿에는 영향 없음

---

### 5️⃣ 템플릿 복제 테스트

#### 테스트 단계
1. **복제 실행**
   - 템플릿 행의 "..." 버튼 → "복제" 선택

2. **복제 확인**
   - ✅ "템플릿이 복제되었습니다" 알림
   - ✅ 목록 자동 새로고침
   - ✅ 새 템플릿 추가됨

3. **복제본 확인**
   - 복제본의 이름: "원본 이름 (복사본)"
   - 상태: "초안" (자동 설정)
   - 모든 다른 정보는 동일

#### 예상 결과
- 원본과 동일한 내용의 새 템플릿 생성
- 이름 끝에 "(복사본)" 추가
- 상태는 자동으로 "초안"으로 설정

---

### 6️⃣ 필터 및 검색 테스트

#### 테스트 단계
1. **검색 기능**
   ```
   검색어: "주문"
   결과: 이름/설명에 "주문"이 포함된 템플릿만 표시
   ```

2. **타입 필터**
   ```
   타입: 이메일
   결과: 이메일 타입 템플릿만 표시
   ```

3. **카테고리 필터**
   ```
   카테고리: 주문
   결과: 주문 카테고리 템플릿만 표시
   ```

4. **상태 필터**
   ```
   상태: 활성
   결과: 활성 상태 템플릿만 표시
   ```

5. **언어 필터**
   ```
   언어: 한국어
   결과: 한국어 템플릿만 표시
   ```

6. **복합 필터**
   ```
   검색어: "주문" + 타입: 이메일 + 상태: 활성
   결과: 모든 조건을 만족하는 템플릿만 표시
   ```

#### 예상 결과
- 필터가 즉시 적용됨
- 여러 필터 동시 사용 가능
- "필터 적용" 버튼으로 수동 새로고침

---

### 7️⃣ 페이지네이션 테스트

#### 조건
- 템플릿이 20개 이상 있어야 함

#### 테스트 단계
1. **페이지 이동**
   - "다음" 버튼 클릭
   - ✅ 2페이지로 이동
   - ✅ "이전" 버튼 활성화

2. **페이지 정보**
   - 현재 페이지 / 전체 페이지 표시
   - 예: "1 / 3"

3. **끝 페이지**
   - 마지막 페이지에서 "다음" 버튼 비활성화
   - 첫 페이지에서 "이전" 버튼 비활성화

#### 예상 결과
- 페이지당 20개씩 표시
- 버튼 활성/비활성 상태 정확함

## 🚀 테스트 자동화 (선택사항)

### API 테스트 스크립트

```powershell
# 1. 관리자 토큰 얻기
$token = "your-admin-token-here"

# 2. 템플릿 생성 테스트
$body = @{
    name = "테스트 템플릿"
    description = "자동 테스트용 템플릿"
    type = "email"
    category = "system"
    priority = "medium"
    language = "ko"
    status = "draft"
    title = "테스트 제목"
    content = "테스트 내용"
    tags = @("test", "auto")
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://localhost:3000/api/admin/notifications/templates" `
    -Method POST `
    -Headers @{ Authorization = "Bearer $token"; "Content-Type" = "application/json" } `
    -Body $body

# 3. 템플릿 목록 조회 테스트
Invoke-RestMethod -Uri "http://localhost:3000/api/admin/notifications/templates" `
    -Method GET `
    -Headers @{ Authorization = "Bearer $token" }
```

## 📞 문제 발생 시

### 일반적인 문제 해결

1. **"인증 토큰이 없습니다" 에러**
   - 다시 로그인
   - localStorage에서 토큰 확인

2. **템플릿이 표시되지 않음**
   - 페이지 새로고침 (F5)
   - 필터 초기화

3. **다이얼로그가 열리지 않음**
   - 브라우저 콘솔 확인
   - 린트 에러 확인

4. **API 오류**
   - 네트워크 탭에서 요청/응답 확인
   - 서버 로그 확인
