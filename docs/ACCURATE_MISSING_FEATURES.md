### 🔴 **우선순위 1: 즉시 필요 (상용화 필수)**

#### 1. **배송 추적 시스템** ⚠️⚠️⚠️
**현재**: 완전히 없음

**필요한 것**:
```
□ 택배사 API 연동 (스위트트래커 추천)
□ Order 모델에 배송 정보 필드 추가
  - courierCompany: string
  - trackingNumber: string
  - shippedAt: Date

□ 관리자/파트너 송장 입력 페이지
  - 주문별 송장 등록 UI
  - 일괄 등록 기능

□ 사용자 배송 조회 페이지
  - 주문 내역에서 "배송 조회" 버튼
  - 실시간 배송 상태
  - 배송 이력 타임라인
```

**API 구조**:
```typescript
POST /api/admin/orders/[id]/shipping
{
  courierCompany: "CJ대한통운",
  trackingNumber: "123456789"
}

GET /api/orders/[id]/tracking
Response: {
  courier: "CJ대한통운",
  trackingNumber: "123456789",
  status: "배송중",
  events: [
    { time: "2025-10-12 10:00", status: "상품 인수", location: "서울" },
    { time: "2025-10-12 14:00", status: "배송중", location: "대전" }
  ]
}
```

**예상 시간**: 1.5주  
**중요도**: ⭐⭐⭐⭐⭐
