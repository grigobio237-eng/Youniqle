# 추천 시스템 개선 가이드

## 개요

신규 사용자에게는 관리자가 추천한 상품을 우선 노출하고, 활동 이력이 있는 사용자에게는 개인화된 추천을 제공하는 시스템으로 개선되었습니다.

## 주요 개선사항

### 1. 신규 사용자 대응
- **관리자 추천 상품 우선 노출**: 활동 이력이 없는 신규 사용자에게는 관리자가 설정한 추천 상품을 70% 비율로 노출
- **인기 상품 보조**: 나머지 30%는 인기 상품으로 채움
- **썰렁함 해소**: 빈 추천 목록으로 인한 사용자 이탈 방지

### 2. 활동 사용자 대응
- **개인화 추천**: 구매 이력이나 행동 데이터가 있는 사용자에게는 기존 알고리즘 기반 개인화 추천 제공
- **활동 기준**: 구매 1회 이상 또는 행동 이력 10개 이상, 프로필 생성 후 7일 이상 경과

### 3. 신상품 최신순 노출
- **실제 DB 연동**: 신상품은 실제 데이터베이스의 최신순 상품을 노출
- **API 개선**: `/api/products/latest` 엔드포인트로 최신 상품 조회

## 파일 구조

### 모델 수정
- `src/models/Product.ts`: `featuredByAdmin`, `adminRecommendationReason` 필드 추가

- `src/app/api/personalization/recommendations/route.ts`: 개인화 추천 API
- `src/app/api/products/latest/route.ts`: 최신 상품 조회 API
- `src/app/api/admin/products/recommend/route.ts`: 관리자 추천 설정 API

### 컴포넌트
- `src/components/personalization/PersonalizedRecommendations.tsx`: AI 개인화 추천
- `src/components/recommendations/RecommendationSection.tsx`: 일반 추천 섹션
- `src/components/admin/ProductRecommendationManager.tsx`: 관리자 추천 관리

### 엔진
- `src/lib/personalizationEngine.ts`: 개인화 추천 엔진 (핵심 로직)
- `src/hooks/useRecommendations.ts`: 추천 훅
- `src/hooks/usePersonalization.ts`: 개인화 훅

## 사용 방법

### 1. 샘플 데이터 생성
```bash
node scripts/create-sample-products.js
```

### 2. 관리자 추천 상품 설정
1. 관리자 페이지 접속: `/admin/products`
2. "추천 관리" 탭 클릭
3. 상품 검색 및 추천 설정
4. 추천 이유 입력 (선택사항)

### 3. 추천 시스템 동작 확인
1. **신규 사용자**: 로그아웃 상태에서 메인페이지 접속
2. **활동 사용자**: 구매 이력이 있는 계정으로 로그인 후 접속

## 추천 로직

### 신규 사용자 (활동 이력 없음)
```
관리자 추천 상품 (70%) + 인기 상품 (30%)
```

### 활동 사용자 (활동 이력 있음)
```
협업 필터링 + 콘텐츠 기반 + 인기 상품 + 트렌딩 상품
```

### 신상품
```
데이터베이스 최신순 상품 (createdAt 기준)
```

## 문제 해결

### 추천이 표시되지 않는 경우
1. 데이터베이스 연결 확인
2. 상품 데이터 존재 여부 확인
3. API 엔드포인트 응답 확인

### 관리자 추천이 작동하지 않는 경우
1. `featuredByAdmin` 필드 설정 확인
2. 상품 상태 (`status: 'active'`, `approvalStatus: 'approved'`) 확인
3. API 권한 확인

### 신상품이 표시되지 않는 경우
1. 상품 생성일 확인
2. 상품 상태 확인
3. API 응답 확인
