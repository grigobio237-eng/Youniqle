쿠폰 데모 데이터 가이드

1) 목적
- 개발/테스트용으로 다양한 유형의 쿠폰을 손쉽게 생성하기 위한 스크립트 사용 안내

2) 생성되는 예시
- 신규회원 10% 쿠폰 (다운로드 후 7일)
- 전 고객 5,000원 고정할인 (고정기간)
- 무료배송 쿠폰 (최소주문 30,000원)
- VIP 15% 쿠폰 (최대 20,000원)

3) 실행 방법
- npm run seed:coupons

4) 주의사항
- JWT_SECRET과 관리자 토큰 정책에 따라 Admin API를 호출할 수 있도록 스크립트가 서버 내부 DB에 직접 기록합니다.
