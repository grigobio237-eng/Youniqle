## 시스템 개요

### ✅ 구현 완료 기능

#### 1. **모델 & 데이터베이스**
- ✅ Notice 모델 (MongoDB)
- ✅ 공지사항 타입: 일반, 중요, 이벤트, 점검, 업데이트
- ✅ 상태: 임시저장, 게시됨, 보관됨
- ✅ 기능: 상단 고정, 중요 표시, 팝업 노출
- ✅ 노출 기간 설정 (시작일, 종료일)
- ✅ 첨부 파일 지원
- ✅ 조회수 자동 카운트

#### 2. **API 엔드포인트**

**사용자용**
- `GET /api/notices` - 공지사항 목록 (게시된 것만)
- `GET /api/notices/[id]` - 공지사항 상세 (조회수 증가)
- `GET /api/notices/popup` - 팝업 공지사항

**관리자용**
- `GET /api/admin/notices` - 전체 공지사항 목록 (상태별)
- `POST /api/admin/notices` - 공지사항 생성
- `GET /api/admin/notices/[id]` - 공지사항 상세
- `PATCH /api/admin/notices/[id]` - 공지사항 수정
- `DELETE /api/admin/notices/[id]` - 공지사항 삭제

#### 3. **페이지**
- ✅ `/notices` - 사용자 공지사항 목록
- ✅ `/notices/[id]` - 사용자 공지사항 상세
- ✅ `/admin/notices` - 관리자 공지사항 관리

#### 4. **컴포넌트**
- ✅ NoticePopup - 팝업 공지사항 표시
- ✅ 헤더 공지사항 링크

## 문제 해결

### ❌ 문제 1: 팝업이 표시되지 않음

**원인:**
- localStorage에 숨김 설정이 저장되어 있음
- 팝업 공지사항이 없음

**해결:**
1. F12 → Console에서 실행:
```javascript
localStorage.removeItem('hiddenNoticePopups')
location.reload()
```

2. 또는 관리자 페이지에서 팝업 공지 생성 확인

### ❌ 문제 2: 관리자 페이지 접근 불가

**원인:**
- 관리자 권한이 없는 계정으로 로그인

**해결:**
1. 관리자 계정으로 로그인:
   - 이메일: `admin@youniqle.com`
   - 비밀번호: `admin123!`

2. 또는 MongoDB에서 사용자 role 변경:
```javascript
db.users.updateOne(
  { email: "your@email.com" },
  { $set: { role: "admin" } }
)
```

### ❌ 문제 3: 데모 데이터 생성 실패

**원인:**
- MongoDB 연결 실패
- MONGODB_URI 환경변수 미설정

**해결:**
1. `.env.local` 파일 확인
2. MONGODB_URI 값 확인
3. MongoDB Atlas 연결 상태 확인

### ❌ 문제 4: 조회수가 증가하지 않음

**원인:**
- 조회수 증가 로직 실행되지 않음

**해결:**
1. 브라우저 캐시 클리어
2. 다른 브라우저에서 테스트
3. API 직접 호출 테스트:
```javascript
fetch('/api/notices/[ID]').then(r => r.json()).then(console.log)
```
